# 🎵 Spotify App Clone

This is a **MERN full stack clone of Spotify** built using. It mimics the look and basic functionality of the Spotify music player interface. This project can be extended into a full-stack app for showcasing in placements or portfolios.

---

## 🚀 Features

- Responsive design similar to Spotify
- Play/Pause songs
- Seek bar to navigate tracks
- Playlist layout with song cover images and names
- Basic audio functionality using the HTML5 `<audio>` element

---

## 📦 Tech Stack

- **HTML**
- **CSS**
- **JavaScript (Vanilla)**
- **mongodb**
- **node.js**
- **react.js**
- **express**
